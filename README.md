# DevOps Exercises

This repository contains a collection of exercises covering various DevOps topics including CI/CD, container orchestration, Kubernetes, cloud-native infrastructure, and more.

## Topics

- CI/CD
- Kubernetes
- Docker
- Infrastructure as Code
- Monitoring & Logging
- Cloud Providers

## Usage

Browse the folders and pick an exercise. Each exercise includes a description and a task. Try to solve it on your own, then compare with the provided solution.

## Contributing

Feel free to open a PR to add new exercises or improve existing ones. Please ensure your contributions are accurate and helpful.
